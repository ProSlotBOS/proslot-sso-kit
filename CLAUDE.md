# Agent rules for this repository

This repository is public. Keep comments, docs and commit messages generic:
no client or organization names, no incident narratives, no people's names or
addresses. Incident history belongs in the maintainers' private notes.

## Sync with origin before working

Before any work here, run `git fetch origin` and pull if the checkout is behind:
other sessions push to `origin/main` at any time. Commit promptly and confirm
each commit holds what you intended, and keep the branch tracking its upstream
so `git status` reports ahead/behind.
